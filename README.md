# NISMPracticeTests.com

Free practice test platform for NISM certification candidates in India.

## Setup

1. Read `CLAUDE.md` for build context and `DESIGN.md` for visual design system.
2. Open `design-reference/tracker.html` in a browser to see the validated UX you're rebuilding.
3. Question pool already seeded in `src/data/exams/nism-va/` — 522 questions, 32 sets.
4. Run with Claude Code: `claude` in this directory, then prompt: "Read CLAUDE.md and start Phase 1".
