# NISM Series VIII — Equity Derivatives

## The exam in numbers

| | |
|---|---|
| Questions | **100** |
| Marks | 100 (1 per Q) |
| Duration | **2 hours** (120 min) |
| Pass mark | **60%** |
| Negative marking | **Yes — 25%** of the marks per wrong answer |
| Validity | 3 years from passing date |
| Mode | Online, Schoolnet interface, NISM-affiliated test centres |

### What that means in practice

- **You can leave a question blank** with no penalty. With negative marking 0.25, you only need to be **>33% likely correct** to make guessing positive-EV. If you have no clue → skip.
- **60% pass mark** is real — most years 30-40% of candidates fail. The free chapter and 5 reference docs here are calibrated to put you at 70%+.
- **2 hours for 100 Qs = 72 sec per Q on average.** Most basics + memory questions take 20-30 sec; numericals on Greeks, payoffs, hedging eat 2-3 min. Budget tight.

## The 4-chapter rule for VIII

If you can score **80%+ on Chapters 3, 4, 5, 6** (60 marks combined) and **50%+ on the rest** (40 × 0.5 = 20 marks) → you clear 60 with margin. That's the practical exam-cracking target.

## Study sequence we recommend

1. **Day 1:** Ch 1 + Ch 2 (foundational vocabulary, easy wins).
2. **Day 2-3:** Ch 3 (futures) — mechanism + pricing + worked examples.
3. **Day 4-5:** Ch 4 (options) — buyer/writer matrix + Greeks + moneyness.
4. **Day 6:** Ch 5 (strategies) — straddle/strangle/covered call/collar/butterfly + put-call parity.
5. **Day 7:** Ch 6 + Ch 7 (trading + clearing) — operational rules.
6. **Day 8:** Ch 8 + Ch 9 + Ch 10 (legal, tax, sales) — memorise.
7. **Day 9-10:** First mock test → review weak topics → second mock → exam.

## A note on negative marking

Most candidates **lose more from wrong answers than from blanks**. Default: skip if you can't narrow to 2 options. Aggressive: with 4 options + zero clue, blind guess gives expected value of 0.25 − 0.75×0.25 = **+0.0625** marks → marginally positive. With 2 options narrowed → +0.375, clear win. **Always answer 2-option-narrow questions; default-skip 4-option blind guesses unless you've finished early.**
