# Content format — copy verbatim from V-A

Every chapter MD must have the three-layer structure:

```
# Chapter N · Title

## 🎯 Summary Card

3-5 bullets. The 60-second version. What a candidate revising the night
before needs to remember.

## 📖 Core Content

The expanded prose, tables, and worked examples. Aim for 800-1500 words
per chapter. Tables for any rule with multiple rows. Code blocks for
formulas (mobile-safe).

## 🧠 Memory Hooks

Mnemonics, number patterns, common-trap callouts. The "why this is
sticky" payload.
```

Copy `src/data/exams/nism-va/study/CONTENT-FORMAT.md` for the full spec
and the V-A chapters as worked examples. **Quality bar = V-A Ch 1.**
