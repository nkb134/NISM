## 🎯 Summary Card

The biggest single chapter (20% of marks). Covers **KYC, account opening, transaction processing, NAV cut-offs, redemption, statement of account, nomination, change of bank/address, online platforms (RTA / AMC / MF Utility), grievance redressal (SCORES, ODR), unclaimed amounts, transmission**. **CKYC is one-time; valid across all SEBI intermediaries.** Common transaction types: **lump-sum, SIP, STP, SWP, switch, redemption, transmission**.

## 📖 Core Content

### KYC (Know Your Customer)

- **Mandatory for every investor** under PMLA + SEBI rules.
- One-time across the industry — **CKYC** (Central KYC) record reused.
- Required documents:
  - **PAN** (proof of identity)
  - **Aadhaar / Voter ID / Passport / DL** (proof of address)
  - **Bank account details** (cancelled cheque)
  - **Photograph**
- **PEP (Politically Exposed Person) screening** — enhanced due diligence required.
- **Re-KYC frequency:** Low-risk = 10 yrs; Medium = 8 yrs; High-risk = 2 yrs.

### Modes of investment

| Mode | Description |
|---|---|
| **Lump-sum** | One-time purchase |
| **SIP (Systematic Investment Plan)** | Fixed amount at fixed intervals (monthly typical) |
| **STP (Systematic Transfer Plan)** | Transfer fixed amount from one scheme to another at intervals |
| **SWP (Systematic Withdrawal Plan)** | Fixed withdrawal at intervals |
| **Switch** | Move investment from one scheme to another (within same AMC or across) |

### NAV cut-off times (recap from Ch 5)

| Scheme | Subscription cut-off | Redemption cut-off |
|---|---|---|
| **Liquid** | 1:30 PM | 3:00 PM |
| **Other** | 3:00 PM | 3:00 PM |

For subscription ≥ ₹2 lakh: NAV applicable based on **funds-realised date**, not application date.

### Nomination (mandatory)

- **Every folio must have a nominee** (or explicit opt-out signed by the investor).
- Up to **3 nominees** allowed; percentages totalling 100%.
- Nomination + opt-out tracked in the folio.
- On investor's death, nominee receives units (transmission process).

### Change requests (post-onboarding)

| Change | Requirement |
|---|---|
| **Bank account** | Cancelled cheque + signed request form |
| **Address** | Address proof + signed form |
| **Nominee** | Signed form (witnessed); replaces existing nominee |
| **Mode of holding** (single ↔ joint) | All holders' consent |
| **Mobile + email** | OTP verification |
| **PAN update** | Self-attested PAN copy |

### Redemption process

1. Investor submits redemption request (online or paper).
2. AMC processes at applicable NAV based on cut-off.
3. **Payout T+2 for equity; T+1 for liquid** (per SEBI guideline).
4. Funds credited to registered bank account (NEFT/RTGS).

### Online platforms

| Platform | Run by |
|---|---|
| **AMC website** | Each AMC's own portal |
| **CAMS / KFin** | Two main RTAs serving multiple AMCs |
| **MF Utility (MFU)** | Industry-utility for cross-AMC transactions |
| **MF Central** | New industry-level portal launched 2021; aggregates all folios |
| **Distributor apps** | Zerodha Coin, Groww, Kuvera, ETMoney, etc. |

### Statement of Account (SoA)

- **Sent monthly via email** for all transactions.
- Reflects every purchase, redemption, dividend, switch.
- Investor can request consolidated statement anytime.
- AMFI's **Consolidated Account Statement (CAS)** combines all MFs across AMCs into a single monthly statement.

### Grievance redressal (high-yield)

Cascade:
1. **AMC's investor service** — first port of call. 30-day window.
2. **AMC's compliance officer** — if unresolved.
3. **AMFI** — second-level escalation.
4. **SEBI's SCORES** (Complaints Redress System) — online portal.
5. **SMARTODR** — Online Dispute Resolution if SCORES unresolved.

### Unclaimed redemption + dividend

- Within **3 years** of becoming due → paid at prevailing NAV.
- After **3 years** → paid at the NAV as of end of 3-year period (not current NAV — otherwise investor benefits from delay).
- AMC publishes list of unclaimed amounts annually.

### Transmission

When the investor dies, units transfer to:
- **Joint holder(s)** if mode of holding is "joint" or "either or survivor".
- **Nominee** if single holder + nominee registered.
- **Legal heir** as per succession certificate / probate if no nominee.

Documents required:
- Death certificate
- KYC of receiving party
- Indemnity / declaration form
- Bank details of recipient

### Investor Awareness

AMCs allocate **at least 0.02% of TER** for investor education. AMFI runs the "Mutual Funds Sahi Hai" campaign.

### Specific account features

- **STP** can be daily, weekly, monthly, quarterly.
- **SWP** can be fixed amount or % of portfolio.
- **SIP** can be paused (subject to AMC's policy) for a few months.
- **Top-up SIP** auto-increases the SIP amount annually (e.g. by 10%).
- **Trigger-based** transactions (NAV-trigger, date-trigger) supported by some AMCs.

- **CKYC = one-time across the industry.**
- **PAN + Aadhaar + bank cheque + photo** = standard KYC docs.
- **Re-KYC: 10 yrs (low risk) / 8 / 2 (high).**
- **NAV cut-off: 3 PM** (other than liquid).
- **Subscription ≥ ₹2 lakh → NAV based on funds-realised date.**
- **Up to 3 nominees** per folio; percentages sum to 100%.
- **Redemption payout T+2 equity; T+1 liquid.**
- **CAS = AMFI's consolidated account statement** across all AMCs.
- **Unclaimed > 3 years → paid at 3-year-end NAV** (not current).
- **Grievance cascade: AMC → AMFI → SCORES → SMARTODR.**
- **Investor awareness: ≥ 0.02% of TER** allocated by AMCs.
- **"Mutual Funds Sahi Hai"** = AMFI's awareness campaign.
