# NISM Series V-B — Mutual Fund Foundation

The "New Cadre" exam — designed to bring MF distribution into Tier-II/III towns and rural India by allowing distributors to sell a curated list of simple, transparent schemes.

## The exam in numbers

| | |
|---|---|
| Questions | **50** |
| Marks | 50 (1 per Q) |
| Duration | **75 min** |
| Pass mark | **50%** (25/50) |
| Negative marking | **No** ❌ |
| Validity | 3 years |

### Notable vs other NISM exams

- **Half the size of V-A** — 50 questions vs 100.
- **No negative marking** — answer everything; never leave a blank.
- **Lower pass mark (50% vs 60% for VIII/XV)** — but still requires solid fundamentals.
- Foundational scope: introduces MF concepts, products the New Cadre can sell, and basics of investor service.

## The 4-chapter rule for V-B

Score **80%+ on Chapters 9, 5, 7, 2** (56 marks combined → ~45 marks at 80%) + **40%+ on the rest** (44 × 0.4 = ~18 marks) → **>30 marks = clear pass with margin**.

## Recommended study sequence

1. **Day 1:** Ch 1 (foundations) + Ch 2 (MF concept).
2. **Day 2:** Ch 3 (legal structure) + Ch 4 (products you can sell).
3. **Day 3:** Ch 5 (scheme info — SID/SAI/KIM, NAV cut-offs).
4. **Day 4:** Ch 6 (distribution + AMFI Code) + Ch 8 (taxation).
5. **Day 5:** Ch 7 (performance).
6. **Day 6-7:** Ch 9 (investor services — biggest chapter).
7. **Day 8:** Ch 10 (regulatory).
8. **Day 9-10:** Mock test → review weak topics → second mock → exam.

## What V-B distributors can sell

A New-Cadre distributor (V-B passed) can sell:
- **Index funds** (Sensex, Nifty 50)
- **Large-cap diversified equity**
- **Gilt funds**
- **FMPs**
- **Equity ETFs + Gold ETFs**
- **Liquid + Ultra-short debt funds**

To sell broader products (mid-cap, sectoral, credit-risk, hybrid, international, derivatives), pass **NISM-V-A** (full distributor exam).

## No negative marking — strategy

Every question should be answered. With 4 options:
- Even a 25% blind guess is +0.25 EV.
- Narrowed to 2 = +0.50 EV.

**Never leave a blank.** Mark something on every question.
