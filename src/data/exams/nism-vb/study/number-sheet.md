# V-B Number Sheet

Print this. Memorise.

## Exam mechanics

| | |
|---|---|

```
75 min for 50 Qs = 90 sec / Q on average
```

## SLR + 5 risks

- **SLR** = Safety, Liquidity, Returns
- **5 risks** = Inflation, Liquidity, Credit, Market, Interest rate

## Investment limits (per scheme)

| Limit | Cap |
|---|---|
| Single company equity | **10%** of NAV |
| MF (across schemes) ownership of single co | **10%** of voting rights |

| Single bank exposure | **15%** of NAV; extendable to **20%** |
| Unrated debt | **10%** of debt portfolio, min investment grade |

## Riskometer

**6 levels:** Low → Low to Moderate → Moderate → Moderately High → High → Very High. Updated **monthly**.

## Scheme categorisation count (Oct 2017)

- **Equity:** 10 + 1 (ELSS)
- **Debt:** 16
- **Hybrid:** 7
- **Solution:** 2
- **Other:** 2

## Tax rates (post-July 2024)

| Type | Rate |
|---|---|
| **Equity STCG** (≤12 months) | **20%** |
| **Equity LTCG** (>12 months) | **12.5%** above ₹1.25 lakh per FY |
| **Debt funds bought after April 1, 2023** | **Slab rate**, no indexation, no LTCG benefit |
| **Old debt** (bought before April 1, 2023) | STCG slab if ≤36 months; LTCG **20% with indexation** if >36 months |
| **Dividends** | Slab rate; TDS 10% if > ₹5,000 / FY |

| Loss | Years |
|---|---|

## Section 80C — ELSS

- Max deduction **₹1.5 lakh** per FY
- Lock-in **3 years** (shortest among 80C)
- Treated as equity scheme post lock-in for cap gains

## Grievance cascade

```
AMC investor service (30 days)
  → AMC compliance officer
    → AMFI
      → SEBI's SCORES
        → SMARTODR
```

## Unclaimed amounts

- Within **3 years** → at prevailing NAV
- After **3 years** → at NAV as of **end of 3-year period** (not current)

## Nomination

- Up to **3 nominees**, percentages sum to 100%.
- Mandatory; explicit opt-out otherwise.

## Advertisement code

- **Performance ads** only if scheme **>1 year old**.
- For **>3 years**: **CAGR for 1, 3, 5 yrs and since inception** mandatory.
- Celebrity endorsements: **industry-level only** + prior SEBI approval.
