# NISM Series VII — Securities Operations and Risk Management

## The exam in numbers

| | |
|---|---|
| Questions | **100** |
| Marks | 100 (1 per Q) |
| Duration | **2 hours** (120 min) |
| Pass mark | **50%** |
| Negative marking | **Yes — 25%** of marks per wrong answer |
| Validity | 3 years |

### Notable

- Mandatory for **back-office, settlement, and risk staff** at brokers/banks.
- **Practical, ops-heavy syllabus** — fewer abstract concepts than V-A; more procedural detail.
- **Ch 3 (Broking Operations) is 20% alone** — biggest single topic.

**Chapters 3 + 4 + 5 + 6 = 65% of marks.** Master operational mechanics.

## The 4-chapter rule

Score **70%+ on Chapters 3, 4, 5, 6** (65 marks → ~46 marks). **40%+ on the rest** (35 × 0.4 = 14). **Total 60+** = comfortable pass.

## Recommended study sequence

1. **Day 1:** Chs 1, 2 (foundation + participants).
2. **Day 2-3:** Ch 3 (broking ops — biggest).
3. **Day 4:** Ch 4 (risk + margin framework).
4. **Day 5:** Ch 5 (clearing) + Ch 6 (settlement).
5. **Day 6:** Ch 7 (grievance) + Ch 8 (other services).
6. **Day 7-8:** Mock test → review weak topics → mock 2 → exam.
