## 🎯 Summary Card

Beyond basic equity trading, brokers offer: **Margin Trading Facility (MTF), F&O, mutual funds, IPO, currency, commodity, ETF, fixed income, demat, research, portfolio reports**. **MTF** = lend money against approved securities; SEBI rules tight (only T-Group stocks excluded; min margin 50%, daily MTM, separate "MTF" demat). **NRIs** trade via PIS / Non-PIS demat accounts. **DPM (Designated Person for Marketing)** rules apply to research dissemination.

## 📖 Core Content

### Service catalogue

| Service | What |
|---|---|
| **Equity cash market** | Delivery + intraday trades |
| **F&O** | Equity / index futures + options |
| **Currency derivatives** | INR pairs (USD/INR, EUR/INR, GBP/INR, JPY/INR) |
| **Commodity** | Gold, silver, crude, agri (via MCX/NCDEX) |
| **MTF (Margin Trading Facility)** | Buy securities with broker-funded leverage |
| **Mutual funds** | Direct + Regular plan distribution |
| **IPO + FPO** | Application via ASBA / UPI |
| **Demat services** | DP services in NSDL / CDSL |
| **Research + advisory** | Subject to SEBI RA / IA rules (separate registration) |
| **Portfolio reports** | Capital gains, holding periods, tax statements |
| **NRI services** | PIS / Non-PIS routes |

### Margin Trading Facility (MTF)

- Broker lends money to client to buy approved securities.
- **Securities held as collateral** in a separate "MTF demat" account.
- **Initial margin: at least 50%** of position value (cash or approved securities).
- **Daily MTM** — top up if collateral falls below threshold.
- **Approved stocks** = Group I securities (top liquidity); excludes T-Group, Z-Group penny stocks.
- **Interest** charged on borrowed amount (typically 12-18% p.a.).
- Position cannot be carried forward beyond regulatory thresholds.

### MTF rules (high-yield)

| Rule | Threshold |
|---|---|
| **Min initial margin** | **50%** of position |
| **Daily MTM** | Yes — top up needed |
| **Eligible securities** | Group I only |
| **Demat account** | Separate "MTF" account |
| **Reporting** | Daily to exchange |
| **Financing source** | Broker's own funds + permitted leverage |
| **Concentration limit** | Per stock + per client + per broker caps |

### NRI trading routes

| Route | Account | Purpose |
|---|---|---|
| **PIS (Portfolio Investment Scheme)** | NRE / NRO + PIS bank account | Repatriable + non-repatriable equity / debt |
| **Non-PIS** | NRO bank | Limited investment, non-repatriable |

- **NRE PIS** — full repatriation; tax on capital gains.
- **NRO PIS** — limited to investments funded from India-source income; non-repatriable.
- **FCNR / NRE FD** — separate bank product, not MTF-eligible.

### Currency derivatives

- INR pairs traded on NSE / BSE / MSEI.
- **Lot sizes** per pair; tick sizes 0.25 paise.
- **Exposure** capped per regulator (RBI + SEBI joint).
- Hedging documentation required for amounts > USD 100 million per fiscal year.

### Commodity derivatives

- Traded on **MCX, NCDEX, ICEX**.
- Regulated by **SEBI** since 2015 (FMC merged into SEBI).
- Categories: bullion, energy, metals, agri.
- Position limits per commodity + per client + per broker.

### IPO / FPO services

- **ASBA (Application Supported by Blocked Amount)** — funds blocked in bank, debited only on allotment.
- **UPI mechanism** — retail-friendly; up to ₹5 lakh per application.
- **Anchor allocation** — qualified institutional buyers commit before public issue.
- **Allotment ratio** — proportional to oversubscription category-wise.

### Research + advisory (separation rules)

- **SEBI RA Regulations 2014** — research analysts.
- **SEBI IA Regulations 2013** — investment advisers.
- Brokers offering research must register separately; same firm can have RA + IA + broker arms with **Chinese walls** between them.
- Personal trading rules apply: **30 days before, 5 days after** recommendation publication.

### Portfolio + tax reporting

Brokers provide:
- **Holding statements** (real-time).
- **P&L reports** (realised + unrealised).
- **Capital gains statements** (STCG / LTCG split for tax filing).
- **STT certificate** (annual, for tax credit).
- **CGS (Capital Gains Statement)** — required for ITR filing in India.

### Cybersecurity + data protection

- Brokers under SEBI's **CSCRF (Cyber Security and Cyber Resilience Framework)**.
- **DPDPA 2023** — data fiduciary obligations on PII.
- **Mandatory annual audits** + breach reporting within 6 hours.

## 🧠 Memory Hooks

- **MTF: 50% min margin, Group I stocks, separate demat, daily MTM.**
- **NRE PIS = full repat; NRO = limited / non-repat.**
- **ASBA + UPI** for retail IPO applications; UPI cap ₹5 lakh.
- **Anchor + QIB + NII + Retail** = IPO allocation buckets.
- **RA Regs 2014, IA Regs 2013** = separate registration regimes.
- **Chinese walls** between research + IB + prop trading desks.
- **CSCRF + DPDPA** = cybersecurity + privacy frameworks; breach report 6 hours.
- **Currency: INR pairs at 0.25-paise tick**; MCX/NCDEX for commodities.
