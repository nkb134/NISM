## 🎯 Summary Card

Three participant blocks: **issuers** (raise capital), **investors** (retail, HNI, institutional), **intermediaries** (exchanges, brokers, RTAs, custodians, MBs, AMCs). Investors classified into **resident, non-resident (NRI/PIO/OCI), FPI, DII**. **Trading Member (TM)** trades, **Clearing Member (CM)** clears; types: SCM, TCM, PCM. **Authorised Person (AP)** replaced sub-brokers in 2019.

## 📖 Core Content

### Three participant blocks

| Block | Examples |
|---|---|
| **Issuers** | Listed companies, PSUs, governments, MFs, REITs |
| **Investors** | Retail, HNI, institutional (banks, insurance, MFs, FPIs, pension funds) |
| **Intermediaries** | Exchanges, brokers, RTAs, custodians, merchant bankers, AMCs, advisers |

### Investor categories

- **Resident individual** — domiciled in India
- **NRI / PIO / OCI** — non-resident Indians; subject to FEMA + RBI / SEBI rules
- **HUF (Hindu Undivided Family)** — separate PAN, can invest in securities
- **Body corporate / partnership / LLP** — subject to MoA / partnership-deed permissions
- **FPI (Foreign Portfolio Investor)** — registered with SEBI; categorized I/II/III by risk profile (Cat-I lowest scrutiny)
- **DII (Domestic Institutional Investor)** — Indian banks, insurance, MFs, pension funds
- **Retail vs HNI** — by ticket size; thresholds vary by IPO category

### Membership categories at the exchange

| Member | Trades | Clears |
|---|---|---|
| **Trading Member (TM)** | ✓ (own + clients) | ✗ (uses a CM) |
| **Trading-cum-Clearing Member (TCM)** | ✓ | ✓ (own + other TMs + custodial participants) |
| **Self Clearing Member (SCM)** | ✓ | ✓ (own only) |
| **Professional Clearing Member (PCM)** | ✗ | ✓ (for TMs + custodial participants) — typically banks/custodians |

### Authorised Person (AP)

- Replaced sub-brokers w.e.f. **April 1, 2019**.
- Acts as **agent of TM** — does NOT directly settle clients.
- One TM can have multiple APs across geographies.
- Mandatory disclosures: AP's name, ARN/registration on every contract note + invoice.

### Bank-based + custodian channels

- **Bank-based brokers** — banks acting as brokers (e.g. ICICI Direct, HDFC Securities). Compete on integration with banking + investment portal.
- **Custodian participants** — large institutional clients (FPIs, MFs) who clear through PCMs but trade through any TM.

### Self-Regulatory Organisations (SROs)

- **AMFI** for mutual funds
- **ANMI / BBF** for stock-broker associations
- SEBI mandates SRO oversight + code of conduct

### Investor classifications for IPOs

| Category | Allocation | Limits |
|---|---|---|
| **QIB (Qualified Institutional Buyer)** | ≥ 50% (book-built) | Lock-in 30 days for anchor portion |
| **NII (Non-Institutional Investor)** | ≥ 15% | HNIs, applied amount > ₹2 lakh |
| **Retail** | ≥ 35% | Application ≤ ₹2 lakh |

## 🧠 Memory Hooks

- **Three blocks: Issuers, Investors, Intermediaries.**
- **Sub-broker → AP w.e.f. April 1, 2019.**
- **Member types:** TM (only trades), TCM (both), SCM (own only), PCM (clears only — bank).
- **FPI categories I/II/III** — Cat-I lowest scrutiny.
- **IPO allocation: QIB ≥ 50%, NII ≥ 15%, Retail ≥ 35%.** Retail = ≤ ₹2 lakh.
- **AP = agent of TM; doesn't settle clients directly.**
