# NISM Series XV — Research Analyst

## The exam in numbers

| | |
|---|---|
| Questions | **100** |
| Marks | 100 (1 per Q) |
| Duration | **3 hours** (180 min) |
| Pass mark | **60%** |
| Negative marking | **Yes — 25%** of marks per wrong answer |
| Validity | 3 years |
| Mode | Online, Schoolnet interface, NISM-affiliated test centres |

### Notable vs other NISM exams

- **Longer duration** (180 min vs the usual 120) — generous time, but expect more numerical questions.
- **15 chapters**, much broader syllabus than V-A or VIII.
- **Heavy on financial analysis (Ch 8, 12%) + valuation (Ch 10, 12%) + technical analysis (Ch 15, 15%).** These three = 39% of marks.

## The 4-chapter rule for XV

If you can score **75%+ on Chapters 8, 10, 14, 15** (49 marks combined → ~37 marks) and **50%+ on the rest** (51 × 0.5 = 25 marks) → you clear 60+ with margin.

## Recommended study sequence

1. **Day 1-2:** Chs 1, 2, 3 (foundations + vocabulary).
2. **Day 3-4:** Chs 4, 5, 6 (research framework + macro + industry).
3. **Day 5-6:** Chs 7, 8 (company qualitative + quantitative).
4. **Day 7:** Ch 9 (corporate actions) + Ch 10 (valuation — the heavy one).
5. **Day 8:** Ch 11 (commodities) + Ch 12 (risk/return).
6. **Day 9:** Ch 13 (research report) + Ch 14 (regulatory).
7. **Day 10-11:** Ch 15 (technical analysis — biggest single chapter).
8. **Day 12-14:** First mock → review weak topics → second mock → exam.
