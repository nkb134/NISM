## 🎯 Summary Card

**NAV = (शुद्ध परिसंपत्तियाँ) ÷ बकाया यूनिट**। ओपन-एंडेड के लिए **दैनिक**, 11 PM तक प्रकट। **TER** SEBI द्वारा AUM-स्लैब से सीमित। **₹2 लाख+ subscription** = funds-realised date NAV। **Direct Plan TER 0.5-1.0% कम**। **Total Return Index (TRI)** बेंचमार्क के लिए (price-only नहीं)।

## 📖 Core Content

### NAV की गणना

```
NAV = (निवेशों का बाजार मूल्य + प्राप्तियाँ − देनदारियाँ) ÷ बकाया यूनिट
```

- **दैनिक** — ओपन-एंडेड के लिए
- **साप्ताहिक/नियतकालिक** — क्लोज़-एंडेड के लिए
- **रात 11 PM तक** AMC + AMFI साइट पर प्रकट

### विस्तृत सूत्र

```
शुद्ध परिसंपत्तियाँ = निवेशों का बाजार मूल्य
                  + प्राप्तियाँ (अर्जित आय, बिक्री प्राप्तियाँ)
                  − देनदारियाँ (अर्जित खर्च, फीस, खरीद)
```

लंबा रूप:

```
NAV = ( + ब्याज
       + लाभांश
       + प्राप्त लाभ
       + मूल्यांकन लाभ
       − प्राप्त हानि
       − मूल्यांकन हानि
       − खर्च
       + carry-forward
       + प्रारंभिक पूँजी
      ) ÷ बकाया यूनिट
```

### TER सीमाएँ — ओपन-एंडेड (Index/ETF/FoF को छोड़कर)

| AUM स्लैब (₹ Cr) | इक्विटी | अन्य |
|---|---|---|
| पहले 500 | **2.25%** | **2.00%** |
| अगले 250 | 2.00% | 1.75% |
| अगले 1,250 | 1.75% | 1.50% |
| अगले 3,000 | 1.60% | 1.35% |
| 5,000 से ऊपर | **1.05%** | **0.80%** |

**AUM बढ़ने पर TER घटता है** — अर्थव्यवस्था का पैमाना।

### Index Funds + ETFs (कम TER)

- **Index Funds**: अधिकतम **1% TER**
- **ETFs**: अधिकतम **1% TER** (आमतौर पर 0.05-0.5% बहुत कम)
- **FoFs (घरेलू)**: अधिकतम **2% TER**
- **FoFs (अंतर्राष्ट्रीय)**: अधिकतम **2.5%**

### NAV applicability

| स्थिति | NAV |
|---|---|
| Subscription < ₹2 लाख, 3 PM से पहले | उसी दिन |
| **Subscription ≥ ₹2 लाख** | **धन-realised date** |
| Liquid फंड subscription, 1:30 PM से पहले | पिछले दिन (carry-back) |
| Redemption, 3 PM से पहले | उसी दिन |

### बेंचमार्क — Total Return Index (TRI)

SEBI नियम: सभी इक्विटी स्कीम **TRI** के विरुद्ध बेंचमार्क की जाएँ (न कि price-only index)।

- **TRI** = price + reinvested dividends
- स्कीम अपने लाभांश पुनर्निवेश करती है — apples-to-apples तुलना के लिए TRI सही है।

### Direct vs Regular Plan की लागत

```
Regular TER = Direct TER + वितरक कमीशन (~0.5-1.0%)
```

10 साल में 1% का अंतर compounded होकर ~10-15% अधिक नेट रिटर्न Direct में।

### Exit Load

- मोचन पर AMC द्वारा वसूला गया शुल्क (आमतौर पर 1% यदि < 1 साल में मोचन)।
- स्कीम के SID में निर्दिष्ट।
- exit load से एकत्रित राशि स्कीम में वापस जाती है (AMC के पास नहीं)।

## 🧠 Memory Hooks

- **NAV = शुद्ध परिसंपत्तियाँ / यूनिट**, दैनिक 11 PM तक।
- **TER पहले 500 Cr (Equity) = 2.25%; 5000 Cr+ = 1.05%**।
- **AUM बढ़े = TER घटे**।
- **₹2 लाख+ = funds-realised NAV**।
- **TRI = price + reinvested dividends** — सही बेंचमार्क।
- **Direct TER ~0.5-1.0% कम** Regular से।
- **Exit load → स्कीम में वापस** (AMC के पास नहीं)।
