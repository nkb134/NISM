## प्रदर्शन अनुपात (सूत्र)

- **Sharpe** = (Rs − Rf) ÷ Standard Deviation
- **Treynor** = (Rs − Rf) ÷ Beta
- **Information Ratio** = (Portfolio Return − Benchmark Return) ÷ SD of Excess Return
- **Alpha** = Actual Return − Expected Return (Beta आधारित)
