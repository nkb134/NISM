# Common Traps

NISM इन्हें plausible-दिखने वाले कथनों के रूप में सेट करना पसंद करता है। नीचे की हर पंक्ति का उत्तर **NO** है। परीक्षा की सुबह यह पढ़ें।

| कथन | वास्तविकता |
|---|---|
| "वितरक सलाह शुल्क ले सकता है" | NO — केवल AMC से कमीशन |
| "ARN 16 साल की उम्र में मिल सकता है" | NO — न्यूनतम 18 |
| "AMC रिटर्न की गारंटी दे सकती है" | NO — MFs pass-through हैं |
| "Sponsor नुकसान के लिए liable है" | NO — केवल प्रारंभिक योगदान तक |
| "Liquid फंड cut-off 3 PM है" | NO — खरीद के लिए **1:30 PM** |
| "Equity STCG धारण अवधि 24 महीने है" | NO — **12 महीने** |
| "नाबालिग के निवेश में nominee हो सकते हैं" | NO — नहीं हो सकते |
| "ELSS lock-in पहले SIP से 3 साल पूरा होता है" | NO — हर किस्त अलग locked |
| "वितरक कमीशन investor को rebate कर सकता है" | NO — AMFI Code द्वारा निषिद्ध |
