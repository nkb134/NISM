# Common Traps

NISM loves to set these up as plausible-sounding statements. Every line below is **NO**. Read this on exam morning.

| Statement | Reality |
|---|---|
| "Distributor can take advisory fee" | NO — only commission from AMC |
| "ARN can be obtained at age 16" | NO — minimum 18 |
| "AMC can guarantee returns" | NO — MFs are pass-through |
| "Sponsor liable for losses" | NO — only initial contribution |
| "Liquid fund cut-off is 3 PM" | NO — it's **1:30 PM** for purchase |
| "Equity STCG holding period is 24 months" | NO — **12 months** |
| "Investments by minors can have nominees" | NO — cannot |
| "ELSS lock-in completes 3 years from first SIP" | NO — each instalment locked separately |
| "Distributor can rebate commission to investors" | NO — prohibited by AMFI Code |
| "STT applicable on debt MF redemption" | NO — only equity-oriented |
| "DDT still exists" | NO — abolished in 2020 |
| "Entry load is allowed for direct plan" | NO — entry load fully banned since 2009 |
| "Body corporate / partnership can be a nominee" | NO — only individuals + government bodies |
| "PoA holder can nominate" | NO |
| "Tracking error is good for active funds" | NO — it's a passive-fund metric; lower = better |
| "Beta = 1 means no risk" | NO — means it moves with the market |
| "Information Ratio is optional disclosure" | NO — mandatory; Sharpe / Treynor / Alpha are optional |
