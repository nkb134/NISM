## 🎯 Summary Card

**Benchmarks:** must be in sync with objective, calculated by independent agency, transparent. **Two-tier benchmarks**: Tier 1 (broad market, comparable across industry), Tier 2 (specific style). **TRI since 1 Feb 2018** (was PRI before). Quantitative measures: **Sharpe** (excess return ÷ SD), **Treynor** (excess return ÷ Beta), **Alpha** (actual − expected return), **Information Ratio** (the only mandatory disclosure — daily, both AMC + AMFI websites). **Tracking Error** for passive funds. Debt scheme benchmark: **10-yr G-sec**.

## 📖 Core Content

### What makes a credible benchmark

- In sync with scheme's objective, allocation, strategy
- Calculated by independent agency
- Transparent and published regularly

Common sources: stock exchanges (Nifty, Sensex), credit rating agencies (CRISIL bond indices), securities research, financial publications.

### Choice of benchmark

- Index funds: clear (the index they track)
- Other schemes: AMC chooses with trustee consultation
- Specified in SID
- AMC can change benchmark with trustee approval (justified + documented)

### PRI vs TRI

| Variant | Captures | Used since |
|---|---|---|
| Price Return Index (PRI) | Capital gains only | Until 31 Jan 2018 |
| Total Return Index (TRI) | Capital gains + dividends/interest | **1 Feb 2018 onwards** |

> Indian dividend yield: 1.5–2.5% historically. TRI shift means fewer schemes appear to beat benchmarks vs PRI era. Reality unchanged; presentation changed.

### Two-tier benchmark structure

| Tier | Purpose |
|---|---|
| Tier 1 | Broad market — comparable across industry within category |
| Tier 2 | Specific to investment style (optional, recommended) |

### Specific category benchmarks

| Category | Benchmark guidance |
|---|---|
| Hybrid & Solution-Oriented | Single broad market or bespoke |
| Thematic / Sectoral | Single (theme-specific) |
| Index Funds & ETFs | Single (the underlying index) |
| FoF (single underlying) | Underlying scheme's benchmark |
| FoF (multiple underlying) | Broad Market Index |
| Debt schemes (general) | **10-year G-sec** |
| Conservative Hybrid | 10-year G-sec |
| Equity Savings | 10-year G-sec |

### Quantitative measures

**Sharpe Ratio (MUST KNOW)**

```
Sharpe = (Rs − Rf) ÷ Standard Deviation
```

- Rs = scheme return; Rf = risk-free rate
- Numerator = risk premium
- Denominator = total risk (SD)
- Higher Sharpe = better risk-adjusted return
- Comparable only across similar schemes

> Worked example — Risk-free 5%, scheme return 7%, SD 0.5%. Sharpe = (7 − 5) ÷ 0.5 = **4**.

**Treynor Ratio**

```
Treynor = (Rs − Rf) ÷ Beta
```

- Same numerator as Sharpe
- Denominator = systematic risk (beta)
- Higher Treynor = better
- Useful only for diversified equity schemes

> Worked example — Risk-free 5%, scheme return 8%, beta 1.2. Treynor = (8 − 5) ÷ 1.2 = **2.5**.

**Alpha**

- Difference between scheme's actual return and expected return (given its beta)
- Positive Alpha → outperformed
- Useful only for actively managed equity schemes

**Information Ratio (MANDATORY DISCLOSURE)**

```
IR = (Portfolio Return − Benchmark Return) ÷ SD of Excess Return
```

- The **only** risk-adjusted measure AMCs MUST disclose
- Disclosed daily on AMC website AND AMFI website
- Tier-1 benchmark used
- Higher = better consistency in beating benchmark

**Tracking Error**

- For passive funds (index, ETF)
- SD of differences between fund return and benchmark return
- **Lower tracking error = better passive fund**
- Measures replication efficiency

### Scheme performance disclosure

- Suitability via product labels and Riskometer
- Cumulative returns for different holding periods
- Discrete annual returns (consistency check)
- Portfolio description (sector spread, market cap, credit quality, etc.)

### Fund factsheets

- Issued monthly by most fund houses (NOT mandatory)
- Subject to SEBI advertising guidelines
- Includes: scheme objective, portfolio, performance, market views
- Common factsheet metrics: market indices, corporate results, government spending, inflation, interest rates, DII/FPI activity, GDP, commodity prices

## 🧠 Memory Hooks

- **Sharpe vs Treynor — "S = SD, T = Tarred (Beta)":** Sharpe uses Standard deviation; Treynor uses Beta. Both have same numerator (excess return).
- **Information Ratio — "Only one Mandated":** among Sharpe/Treynor/Alpha/IR, only **IR** is mandatory disclosure on AMC + AMFI sites daily.
- **Tracking Error — "lower is better for passive":** passive fund's job is to mirror, not beat. Less deviation = better.
- **TRI vs PRI — "TRI is total (incl dividends), PRI is price-only":** since Feb 2018, all comparison uses TRI.
- **Debt benchmark — "10-year G-sec":** easiest one; appears for all general debt schemes, conservative hybrid, equity savings.
- **Two-tier benchmark — "T1 broad, T2 style":** T1 mandatory for category comparison, T2 optional for style.
- **Beta — useful only for "diversified equity":** not for sectoral, debt, or hybrid.
- **Alpha — useful only for "actively managed equity":** passive funds shouldn't have alpha by design.
